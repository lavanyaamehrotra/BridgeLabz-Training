# 🚀 Refresher Training

This repository contains my daily refresher training tasks, covering SQL, DBMS, C#, .NET, and other backend development concepts.

---

## 📅 Day 1 – DBMS & SQL Fundamentals

### 📖 Topics Covered
- Introduction to Relational Databases (RDBMS)
- SQL Server and Database Creation
- Database Schema Design
- Table Creation using DDL Commands
- Primary Keys and Foreign Keys
- Entity Relationship (ER) Diagram
- One-to-Many Relationships
- Data Integrity using Constraints

### 🛠️ Practical Task
Developed a **Health Clinic Database** using SQL Server.

### 📂 Database Name
`HealthClinicDB`

### 📋 Tables Created
- Doctor
- Patient
- Appointment

### 🔗 Relationships
- One Doctor ➜ Many Appointments
- One Patient ➜ Many Appointments

### 📁 Files
- `database.sql` – SQL script for creating the database, tables, and relationships.
- `ER_Diagram.png` – Entity Relationship Diagram of the Health Clinic Database.

### 🎯 Learning Outcomes
- Understood relational database concepts.
- Designed database schemas using SQL Server.
- Implemented primary and foreign key constraints.
- Created and managed database relationships.
- Generated and documented an ER Diagram.
